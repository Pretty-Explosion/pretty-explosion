# Pretty Explosion — BC setup checklist (educational)

**Not legal, tax, or securities advice.** Confirm with a BC lawyer and CPA before filing.

## Recommended direction (typical for Luke’s goals)

Given: BC-based, client contracts, AI products, payment links, possible Seed/partners later.

**Default recommendation to discuss with professionals:** incorporate a **BC limited company** aiming for **CCPC** (Canadian-controlled private corporation) status when ownership qualifies — better liability separation and a cleaner home for capital, contracts, and Stripe/bank accounts than a bare sole prop long-term.

**Also valid early path:** operate briefly as a **sole proprietorship** (or sole prop with registered trade name) while validating revenue, then incorporate (ask CPA about tax-efficient transition).

**Usually skip for now:** federal incorporation unless you specifically need Canada-wide corporate name strategy (adds extra BC registration/filings).

### Rough comparison
| | Sole prop | BC Ltd company |
|---|---|---|
| Liability | Personal | Separate entity (still insure) |
| Admin | Lower | Higher (T2, annual report, minute book) |
| Bank / Stripe / contracts | Possible | Cleaner for a “company” brand |
| Investors / Seed story | Awkward | More natural |

## Registry & tax accounts
- [ ] Name search / NUANS-style approval if naming “Pretty Explosion …”
- [ ] Register via **BC Registries** (sole prop / partnership) or **Corporate Online** (BC company)
- [ ] CRA **Business Number (BN)**
- [ ] **GST/HST** program account — required when you stop being a “small supplier” (commonly the ~$30k taxable supplies threshold; voluntary earlier often useful for ITCs). BC generally charges **GST 5%** (not HST); ask CPA about **PST** on any taxable software/services
- [ ] **Payroll** program account before first employee or if paying yourself salary via corp
- [ ] Corporate tax account (if incorporated)
- [ ] **WorkSafeBC** if you have workers / certain contractor situations (confirm)

## Money & ops accounts (seamless stack)
- [ ] **Business bank account (CAD)** — in the legal name of the entity
- [ ] **Stripe (Canada)** — payment links; payout to business bank; tax settings with CPA
- [ ] Bookkeeping: **Xero / QuickBooks / Wave** + receipts folder
- [ ] **Domain** + **Google Workspace** (or equivalent) email `@yourdomain`
- [ ] Business **insurance** (CGL / cyber / E&O as advised)
- [ ] Optional: **Interac e-Transfer** business, Wise (if cross-border later)

## Product / AI stack (non-government)
- [ ] Hosting (Vercel/etc.) + **Origin**/repo when deploying
- [ ] LLM API keys only when leaving mock Grant AI
- [ ] Analytics (optional; privacy-aware for Canada)
- [ ] Customer support inbox

## Hard cautions (BC / Canada)
- Don’t sell “returns,” tokens, or investment products without proper registration advice
- Invest page language stays informational — not an offering
- Privacy: PIPEDA / BC PIPA awareness for client data
- Contracts + change orders for creative work

## Who to book first
1. BC business lawyer (structure + minute book if corp)
2. CPA familiar with CCPCs / GST in BC
3. Then bank + Stripe + domain email
